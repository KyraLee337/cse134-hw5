# Configuration

## About
Replicated the `Home` and `About` page of my portfolio using Astro and it used a shared `Footer.astro` in replacement of the copied footer component.


## Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
